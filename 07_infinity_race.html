무한대 경주 — ∞/∞와 자라는 속도

핵심 질문 — 분자와 분모가 둘 다 끝없이 커질 때, 그 비는 어디로 갈까? 로피탈은 여기서도 쓸 수 있을까?

02장의 경주는 「누가 먼저 0에 닿나」였어요. 이번엔 반대로 「누가 더 빨리 끝없이 커지나」예요. 이런 ∞/∞ 꼴에도 로피탈의 정리를 쓸 수 있어요. 덕분에 ln x, x², eˣ의 자라는 빠르기를 깔끔하게 줄 세울 수 있어요. 단, 미분해도 끝나지 않는 「무한 루프」 함정이 하나 있어요.

0.0045x = 10에서 x²/eˣ

처음 오신 분께 — 이 페이지를 3줄로

  1. 무엇을: 분자와 분모가 함께 ∞로 가는 ∞/∞ 꼴에 로피탈을 쓰는 법과, 함수들이 자라는 빠르기의 순서(log < 거듭제곱 < 지수)를 배웁니다.
  2. 왜 중요한가: 「어떤 프로그램이 데이터가 커질수록 얼마나 느려지나」, 「인구·바이러스·이자가 얼마나 빨리 불어나나」를 비교하는 데 이 순서를 써요.
  3. 생활·현장에서는: 컴퓨터 알고리즘의 속도 비교(로그 시간 vs 다항 시간 vs 지수 시간)가 바로 이 경주예요. 지수 시간이 걸리는 방법은 데이터가 조금만 커져도 쓸 수 없게 돼요.

미분을 아직 잘 몰라도 됩니다. 필요한 것은 장 안에서 처음부터 다시 설명해요. 그림을 움직여 보고, 밑줄 친 말을 누르면 뜻이 나옵니다.

1단계 · ∞/∞에도 로피탈 — ln x / x와 x²/eˣ

방법: 0/0과 같은 절차일상: 끝없이 늘어나는 두 줄
박사

상황 질문 — 두 가게의 손님 줄이 둘 다 끝없이 길어지고 있어요. 「두 줄 길이의 비」는 결국 어디로 갈까요? 둘 다 끝없으니 비도 모르는 걸까요?

왜 이 방법을 쓰나

  1. 문제 상황: lim (x→∞) ln x / x처럼 분자·분모가 함께 ∞로 가는 극한을 구하고 싶어요.
  2. 앞 방법의 한계: 대입하면 ∞/∞ — 0/0처럼 정해지지 않은 꼴이에요. ∞는 수가 아니라서 나눌 수도 없어요.
  3. 해법: 로피탈의 정리는 ∞/∞에도 성립해요: 분자·분모를 따로 미분해 비의 극한을 봐요.
쉽게 말하면 — 줄의 길이 대신 「줄이 늘어나는 빠르기」를 비교한다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

ln x를 미분하면 1/x라고 했죠? 그럼 (1/x)/1이 돼요?

학교 수학으로 보면: 03장 미분 공식 카드: (ln x)′ = 1/x, (xⁿ)′ = n·xⁿ⁻¹, (eˣ)′ = eˣ.

식 조각읽는 법뜻
ln x / x대입(x → ∞): ∞/∞ → 미분
(1/x) / 1분자 (ln x)′ = 1/x, 분모 (x)′ = 1 → x → ∞이면 0/1 = 0
x²/eˣ → 2x/eˣ → 2/eˣ∞/∞가 두 번 나와서 두 번 미분, 마지막은 2/∞ → 0
숫자로 한 번 해 보기

x = 10: ln 10/10 = 2.303/10 = 0.230

x = 100: 4.605/100 = 0.046

x = 1000: 6.908/1000 = 0.0069 → 0으로

x²/eˣ: x = 10이면 100/22026 = 0.0045, x = 20이면 0.00000082

조수 하루 (수강생)

ln x도 끝없이 커지지만, x가 훨씬 빨리 커져서 비는 0으로 가는구나.

일상으로 치면

두 줄 모두 끝없이 길어져도, 한 줄은 1분에 1명, 다른 줄은 1분에 100명씩 늘면 길이 비는 결국 늘어나는 빠르기의 비를 따라가요.

수학에서는

lim ln x / x = lim (1/x)/1 = 0, lim x²/eˣ = lim 2x/eˣ = lim 2/eˣ = 0. ∞/∞에서도 「대입 → 부정형이면 따로 미분 → 다시 대입」 절차는 그대로예요.

두 문제를 버튼으로 풀어 보세요. 0/0일 때와 무엇이 같고 무엇이 다른가요?

주판봇

∞ 나누기 ∞는 1이죠! 같은 무한대니까!

초파리 연구원

무한대에도 빠르기가 있어. 02장 경주의 ∞ 버전이야.

로피탈 걸음 — ∞/∞ 두 문제

풀이 — 한 걸음씩

  1. ln x / x: 대입 ∞/∞ → (1/x)/1 → 0/1 = 0. 멈춤.
  2. x² / eˣ: ∞/∞ → 2x/eˣ: 아직 ∞/∞ → 2/eˣ: 2/∞ → 0. 멈춤.
  3. 절차는 0/0과 같아요: 매번 대입, 부정형인 동안만 미분.
  4. 결과: 로그는 직선보다 느리게, 거듭제곱은 지수보다 느리게 자라요.
이 단계의 한계 — ∞/∞에서 로피탈이 맞는 이유는 04장 확대경 그림으로는 설명되지 않아요(a에서의 함수값이 없으니까요). 정확한 증명은 이 시리즈 범위 밖이에요.
박사의 해석 — 「둘 다 끝없이 커진다」는 정보만으로는 비를 몰라요. 늘어나는 빠르기(기울기)를 비교하면 정해져요. 0/0과 ∞/∞는 같은 이야기의 두 얼굴이에요.

2단계 · 자라는 빠르기 순서 — log < 거듭제곱 < 지수

방법: 두 함수 비의 표일상: 소문이 퍼지는 빠르기
박사

상황 질문 — 소문이 한 사람씩 퍼지는 것과, 들은 사람마다 두 명에게 전하는 것. 처음엔 비슷해 보여도 결국 차이가 얼마나 날까요?

일상으로 치면

한 사람씩 퍼지는 소문(거듭제곱처럼)과 들은 사람이 모두 두 명에게 전하는 소문(지수처럼)은, 처음 며칠은 비슷해도 결국 비교할 수 없을 만큼 차이가 나요.

수학에서는

로피탈을 반복하면: ln x ≪ x ≪ x² ≪ x⁵ ≪ eˣ (≪는 「비가 0으로 갈 만큼 느리다」). x⁵/eˣ는 다섯 번 미분하면 120/eˣ → 0. x = 10에서는 x⁵가 훨씬 크지만, x = 100에서는 비가 사실상 0이에요.

박사

위에 x⁵, 아래에 eˣ를 고르고 x를 10부터 1000까지 키워 보세요.

주판봇

x = 10에서 x⁵가 eˣ의 4.5배! 제 말이 맞죠?

초파리 연구원

극한은 「끝」의 이야기야. x를 100까지 키워 보고 다시 말해.

자라기 경주 — 두 함수 고르기

풀이 — 한 걸음씩

  1. x = 10: x⁵ = 100,000, eˣ ≈ 22,026 → 비 약 4.5. 거듭제곱이 앞서요.
  2. x = 50: 비 약 6×10⁻¹⁴ (0.00000000000006). 지수가 역전.
  3. x = 100: 비는 0에 아주 가까움. 로피탈 다섯 번이면 120/eˣ → 0으로 증명돼요.
  4. 어떤 거듭제곱 xⁿ도 결국 eˣ에 져요. 그리고 ln x는 어떤 xⁿ (n > 0)에도 져요.
이 단계의 한계 — 「결국」이 언제부터인지는 식마다 달라요. x¹⁰⁰/eˣ는 x가 수백이 넘어야 지수가 역전해요. 극한은 「충분히 큰 x」에서만 말해 줘요.
박사의 해석 — 컴퓨터 과학에서 「지수 시간 알고리즘은 큰 데이터에 못 쓴다」는 말이 바로 이 순서예요. 작은 데이터로만 시험하면 속을 수 있어요.
3

3단계 · 무한 루프 — 로피탈이 제자리를 도는 문제

방법: 최고차항으로 나누기일상: 회전문에 갇힘
박사

상황 질문 — 회전문을 밀었는데 한 바퀴 돌아 다시 같은 자리예요. 계속 밀면 언젠가 나갈 수 있을까요? 아니면 다른 문을 찾아야 할까요?

왜 이 방법을 쓰나

  1. 문제 상황: lim (x→∞) x/√(x² + 1)을 구하고 싶어요.
  2. 앞 방법의 한계: ∞/∞라서 로피탈을 쓰면 √(x² + 1)/x, 한 번 더 쓰면 다시 x/√(x² + 1). 조건은 다 맞는데 끝나지 않아요.
  3. 해법: 분자·분모를 x로 나눠요: x/√(x² + 1) = 1/√(1 + 1/x²) → 1/√1 = 1.
쉽게 말하면 — 회전문이 돌기만 하면 옆의 일반 문으로 나간다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

√(x² + 1)을 미분하면 왜 x/√(x² + 1)이에요? 공식 카드에 없었는데요.

학교 수학으로 보면: 고등학교 합성함수의 미분. 이 단계에서는 결과만 써도 괜찮아요.

식 조각읽는 법뜻
(√(x² + 1))′ = x/√(x² + 1)합성함수 미분의 결과(여기서만 한 번 써요)
x/√(x² + 1) → √(x² + 1)/x로피탈 1번: 분자 1, 분모 x/√(x² + 1) → 정리하면 뒤집힌 꼴
1/√(1 + 1/x²)x로 나눈 꼴. x → ∞이면 1/x² → 0 → 1
숫자로 한 번 해 보기

x = 10: 10/√101 = 10/10.05 = 0.995

x = 100: 100/√10001 = 0.99995

1로 모여요

로피탈 대신 「가장 큰 항 x로 나누기」 한 번으로 끝

조수 하루 (수강생)

로피탈이 만능 열쇠가 아니구나. 돌기만 하면 다른 문을 찾아야겠어요.

일상으로 치면

회전문은 아무리 밀어도 같은 자리로 돌아와요. 그럴 땐 계속 미는 게 아니라 옆의 일반 문을 찾아요.

수학에서는

x/√(x² + 1)에 로피탈을 쓰면 식이 뒤집혔다 돌아왔다를 반복해요. 로피탈이 「틀린」 게 아니라 「답을 내지 못하는」 거예요. 이때는 분자·분모를 가장 큰 항(x)으로 나누는 방법이 바로 답 1을 줘요.

박사

②를 세 번 눌러 보세요. 세 번째 식이 어떻게 되나요?

초파리 연구원

첫 식이랑 똑같아졌어. 백 번 해도 똑같아. 문을 바꿔.

로피탈 걸음 — 무한 루프

풀이 — 한 걸음씩

  1. x/√(x² + 1): ∞/∞ → 미분.
  2. √(x² + 1)/x: 여전히 ∞/∞ → 미분.
  3. x/√(x² + 1): 처음 식과 똑같아요. 무한 루프!
  4. 해결: 분자·분모를 x로 나누면 1/√(1 + 1/x²) → 1. 표로도 0.995, 0.99995 → 1.
이 단계의 한계 — 무한 루프 말고도 「미분할수록 식이 복잡해지는」 경우가 있어요. 그때도 약분·나누기·바꿔 쓰기 같은 다른 도구가 더 나아요.
박사의 해석 — 도구가 막히면 도구 탓도, 문제 탓도 아니에요. 도구를 바꿀 때라는 신호예요. AI가 같은 계산을 끝없이 반복하면 그것도 같은 신호예요.
원자료 인포그래픽 보기 (영어 그림)

원자료 인포그래픽에는 무한 루프 사례가 없어요. 이 단계는 함께 받은 「로피탈 오용 사례」 글의 3번(미분할수록 복잡해지는 경우)을 바탕으로 했어요.

AI 판단 코너 — AI가 낸 답, 그대로 믿어도 될까?

주판봇이 AI에게 「x⁵와 eˣ 중 x가 커질 때 더 빨리 자라는 건?」이라고 물었어요.

AI 답변: x = 10일 때 x⁵ = 100,000이고 e¹⁰ ≈ 22,026이므로 x⁵가 더 빨리 자랍니다. 따라서 lim (x→∞) x⁵/eˣ = ∞입니다.
박사

AI가 「한 점의 값」으로 「끝의 행동」을 말하면 의심하세요. x를 10배, 100배 키운 값을 하나만 더 물어보면 들통나요.
