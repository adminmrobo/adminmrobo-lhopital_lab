변신시켜 쓰기 — 0·∞, 1^∞, ∞−∞

핵심 질문 — 0 × ∞나 1^∞처럼 분수가 아닌 부정형은, 어떻게 로피탈을 쓸 수 있는 꼴로 바꿀까?

로피탈은 0/0과 ∞/∞, 두 가지 「분수 꼴」에만 써요. 그런데 0 × ∞, 1^∞, ∞ − ∞도 대입만으로는 답을 모르는 부정형이에요. 이런 식은 바로 미분하면 안 되고, 먼저 분수 꼴로 「변신」시켜야 해요. 변신 방법은 두 가지: 나눗셈으로 바꾸기, 로그 씌우기.

1

1단계 · 0 × ∞ — 줄다리기를 분수로

방법: 곱을 나눗셈으로 바꾸기일상: 줄다리기
박사

상황 질문 — 한쪽은 0으로 끌어당기고(x), 다른 쪽은 −∞로 끌어당겨요(ln x). 줄다리기의 결과, 곱 x · ln x는 어디로 갈까요?

왜 이 방법을 쓰나

  1. 문제 상황: lim (x→0⁺) x · ln x를 구하고 싶어요.
  2. 앞 방법의 한계: 대입하면 0 × (−∞) — 부정형이에요. 그리고 곱의 꼴이라 로피탈을 바로 쓸 수 없어요.
  3. 해법: x를 1/x로 분모에 보내요: x · ln x = ln x ÷ (1/x). 이제 −∞/∞ 꼴 → 로피탈: (1/x) ÷ (−1/x²) = −x → 0.
쉽게 말하면 — 줄다리기를 「누가 더 빨리 커지나」 경주로 바꾼다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

x를 1/x로 보낸다는 게 무슨 뜻이에요? 값이 바뀌지 않아요?

학교 수학으로 보면: 중학교 분수: a × b = b ÷ (1/a). 예: 3 × 4 = 4 ÷ (1/3) = 12.

식 조각읽는 법뜻
x · ln x0 × (−∞) 꼴 — 로피탈 무대 입장 불가
ln x / (1/x)같은 값을 분수로 쓴 것. −∞/∞ 꼴 → 입장 가능
(1/x) / (−1/x²) = −x분자 (ln x)′ = 1/x, 분모 (1/x)′ = −1/x² → 정리하면 −x → 0
숫자로 한 번 해 보기

x = 0.1: 0.1 × ln 0.1 = 0.1 × (−2.303) = −0.230

x = 0.01: −0.046

x = 0.001: −0.0069 → 0으로

줄다리기는 x(0으로 가는 쪽)가 이겨요

조수 하루 (수강생)

곱셈을 나눗셈으로 바꿨을 뿐인데 로피탈을 쓸 수 있게 됐어요. 옷만 갈아입은 거네요!

일상으로 치면

줄다리기에서 양쪽 다 세게 당기면, 결과는 누가 「더 빨리」 힘을 키우냐로 정해져요.

수학에서는

x · ln x에서 x는 0으로, ln x는 −∞로 가요. ln x/(1/x)로 바꾸면 ∞/∞ 꼴이 되고, 로피탈로 −x → 0. x가 로그보다 「빨리」 0으로 가서 이겨요(07장의 순서와 같은 이야기).

박사

x를 0.000001까지 줄여 보세요. 곱은 어디로 가나요?

주판봇

초파리 연구원

−∞는 「무엇이든」에 안 들어가. 0 × ∞는 경주야. 표를 봐.

줄다리기 실험 — x · ln x

풀이 — 한 걸음씩

  1. x = 0.1: x · ln x = −0.230.
  2. x = 0.001: −0.0069. 0에 가까워져요.
  3. 분수로 바꾸면 ln x/(1/x) → 로피탈 → −x → 0.
  4. 이 결과가 11장 AI 손실 함수의 「0 · log 0 = 0」 약속의 근거예요.
이 단계의 한계 — 어느 쪽을 분모로 보낼지 잘못 고르면 식이 더 복잡해질 수 있어요. 예: x/(1/ln x)로 바꾸면 미분이 훨씬 어려워요. 미분하기 쉬운 쪽(로그가 아닌 쪽)을 내려 보내요.
박사의 해석 — 0 × ∞는 「작아지는 힘과 커지는 힘의 줄다리기」예요. 분수 옷을 입히면 07장의 「자라는 빠르기」 비교가 되어 승패가 정해져요.

2단계 · 1^∞ — 복리 이자의 끝, e

방법: ln을 씌워 지수 끌어내리기일상: 은행 이자를 자주 붙이기
박사

상황 질문 — 연 100% 이자를 1년에 한 번 붙이면 2배. 반년마다 50%씩 두 번 붙이면? 매달, 매일, 매초 붙이면 끝없이 불어날까요?

왜 이 방법을 쓰나

  1. 문제 상황: lim (n→∞) (1 + 1/n)ⁿ을 구하고 싶어요.
  2. 앞 방법의 한계: 대입하면 1^∞. 「1을 몇 번 곱해도 1」 같지만, 밑이 1보다 「조금」 크면서 지수가 끝없이 커지는 경주라 부정형이에요.
  3. 해법: ln을 씌워요: ln((1 + 1/n)ⁿ) = n · ln(1 + 1/n) — 이건 ∞ × 0 꼴 → 1단계처럼 분수로 → ln(1 + 1/n)/(1/n) → 로피탈 → 1. 그래서 원래 값은 e¹ = e.
쉽게 말하면 — 거듭제곱 경주는 로그로 바꾸면 곱셈 경주가 된다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

ln을 씌웠다가 다시 e로 돌린다는 게 헷갈려요.

학교 수학으로 보면: 고등학교 지수·로그: ln(aᵇ) = b · ln a, 그리고 e^(ln A) = A.

식 조각읽는 법뜻
A = (1 + 1/n)ⁿ구하려는 값. 1^∞ 꼴
ln A = n · ln(1 + 1/n)로그로 지수를 앞으로. ∞ × 0 꼴
ln A → 1t = 1/n로 두면 ln(1 + t)/t → 로피탈 → 1/(1 + t) → 1
A → e¹ = eln A가 1로 가니 A는 e로
숫자로 한 번 해 보기

n = 1: 2배

n = 12 (매달): 2.6130배

n = 365 (매일): 2.7146배

n = 1,000,000: 2.71828배 → e = 2.718281828…를 넘지 못함

조수 하루 (수강생)

1을 몇 번 곱해도 1이 아니었네요. 1보다 아주 조금 큰 수를 아주 많이 곱하면, e라는 벽까지 가는구나!

일상으로 치면

이자를 자주 붙일수록 돈은 늘지만, 매초 붙여도 무한히 늘지는 않아요. 연 100%면 원금의 약 2.718배가 한계예요.

수학에서는

(1 + 1/n)ⁿ → e = 2.71828…. 1^∞ 꼴은 ln을 씌워 ∞ × 0 → 분수 꼴로 바꾼 뒤 로피탈로 풀어요. 실전 연습장의 「복리 은행」에서 직접 운영해 볼 수 있어요.

박사

n을 1부터 1,000,000까지 올려 보세요. 막대가 초록 점선을 넘나요?

주판봇

1을 백만 번 곱하면 1이죠. 답은 1!

초파리 연구원

1이 아니라 1.000001이야. 그걸 백만 번 곱하는 경주라고.

복리 실험 — (1 + 1/n)ⁿ

풀이 — 한 걸음씩

  1. n = 1: (1 + 1)¹ = 2. n = 2: 1.5² = 2.25. n = 12: 2.6130.
  2. n이 커질수록 늘지만, 늘어나는 폭은 점점 줄어요.
  3. ln을 씌우면 n · ln(1 + 1/n) → 1 (로피탈), 그래서 값은 e로.
  4. 「1^∞ = 1」은 오답. 밑이 정확히 1이면 1이지만, 1로 「다가가는」 밑은 경주예요.
이 단계의 한계 — 이 그림은 연 이율 100%만 봤어요. 이율 r이면 한계는 eʳ예요(실전 연습장에서 확인). 실제 예금은 세금·수수료 때문에 이 계산과 달라요.
박사의 해석 — 1^∞는 「아주 작은 성장을 아주 많이 반복」하는 꼴이에요. 그 끝이 e라서, 연속적으로 자라는 모든 것(이자, 세포, 인구 모형)에 e가 나와요.

3단계 · ∞ − ∞ — 통분해서 하나의 분수로

방법: 통분일상: 두 큰 금액의 차이
박사

상황 질문 — 두 회사의 매출이 둘 다 끝없이 커져요. 「매출 차이」도 끝없이 커질까요, 아니면 어떤 값으로 모일까요?

일상으로 치면

두 큰 금액이 함께 커져도, 차이는 0일 수도, 일정할 수도, 커질 수도 있어요. 「둘 다 크다」만으로는 차이를 몰라요.

수학에서는

lim (x→0) (1/x − 1/sin x)는 ∞ − ∞ 꼴이에요. 통분하면 (sin x − x)/(x sin x) — 0/0 꼴 → 로피탈 두 번: (cos x − 1)/(sin x + x cos x) → (−sin x)/(2cos x − x sin x) → 0/2 = 0.

박사

표의 식을 1/x − 1/sin x로 바꾸고 자릿수를 올려 보세요.

주판봇

∞ 빼기 ∞는 0이죠. 같은 무한대끼리니까!

초파리 연구원

이번엔 우연히 0이 맞아. 하지만 「같은 무한대니까」는 틀린 이유야. 1/x − 1/x²는 −∞로 가거든.

∞ − ∞ 표 — 1/x − 1/sin x

풀이 — 한 걸음씩

  1. x = 0.1: 1/0.1 − 1/sin 0.1 = 10 − 10.0167 = −0.0167.
  2. x = 0.01: −0.00167. 0으로 모여요.
  3. 통분: (sin x − x)/(x sin x) → 0/0 → 로피탈 두 번 → 0.
  4. 주판봇의 답 0은 맞았지만 이유가 틀렸어요. 1/x − 1/x²는 같은 ∞ − ∞인데 −∞로 가요.
이 단계의 한계 — 통분이 늘 쉬운 것은 아니에요. 루트가 섞인 ∞ − ∞는 「켤레식 곱하기」 같은 다른 변신이 필요해요. 이 시리즈에서는 다루지 않아요.
박사의 해석 — 부정형의 공통점: 「한쪽의 힘」만 보고 답을 정할 수 없다는 것. 변신은 두 힘을 한 분수 안에 넣어 경주시키는 일이에요.
더 알고 싶은 분께 — 정확한 정의 (몰라도 됩니다)

참고로 sin x = x − x³/6 + …를 쓰면 1/x − 1/sin x ≈ −x/6 이라서 0으로 가는 빠르기까지 알 수 있어요(x = 0.01이면 −0.00167). 이런 전개를 테일러 급수라고 해요.

AI 판단 코너 — AI가 낸 답, 그대로 믿어도 될까?

모아가 AI에게 「lim (n→∞) (1 + 1/n)ⁿ은?」이라고 물었어요.

AI 답변: n → ∞이면 1/n → 0이므로 1 + 1/n → 1입니다. 1을 몇 번 거듭제곱해도 1이므로 극한은 1입니다.
박사

극한에서 「한 부분만 먼저 극한값으로 바꾸기」는 위험해요. AI가 그렇게 하면 n = 1000 같은 값을 직접 넣어 보세요.

(1 + 1/n)ⁿ, n = 1,000,000. 주판봇은 「1」, 초파리는 「e 근처」에 걸었어요.
