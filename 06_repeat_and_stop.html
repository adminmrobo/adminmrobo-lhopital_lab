한 번 더 미분 — 반복과 멈춤

핵심 질문 — 로피탈로 미분했는데도 또 0/0이 나오면 어떻게 할까? 그리고 언제 멈춰야 할까?

05장의 세 문제는 한 번 미분으로 끝났어요. 하지만 원자료 인포그래픽의 예제 (1 − cos x)/x²는 한 번 미분해도 0/0이에요. 그럴 땐 한 번 더 미분해요. 단, 매번 대입해서 꼴을 확인하고, 보통 수가 나오면 바로 멈춰요.

2번그 예제에 필요한 미분 횟수
0.49958x = 0.1에서 실제 값

처음 오신 분께 — 이 페이지를 3줄로

  1. 무엇을: 로피탈을 한 번 써도 다시 0/0(또는 ∞/∞)이 나오면 한 번 더 쓰는 반복 적용과, 언제 멈추는지를 배웁니다.
  2. 왜 중요한가: 많은 극한 문제가 두세 번의 미분으로 풀려요. 반대로 「멈출 곳」을 놓치면 바로 오답이 나와요(09장). 반복과 멈춤은 한 쌍이에요.
  3. 생활·현장에서는: 공학에서 「1차 근사로 안 되면 2차 근사까지 본다」는 생각과 같아요. 출발 속도가 같으면 가속도를 비교하는 셈이에요.

미분을 아직 잘 몰라도 됩니다. 필요한 것은 장 안에서 처음부터 다시 설명해요. 그림을 움직여 보고, 밑줄 친 말을 누르면 뜻이 나옵니다.

1

1단계 · 원자료 예제 — (1 − cos x)/x²를 두 번 미분

방법: 로피탈 두 번일상: 출발 속도가 같은 두 선수
박사

상황 질문 — 두 선수가 동시에 출발했는데 출발 속도가 둘 다 0이에요(정지 상태에서 출발). 출발 직후 누가 앞서는지는 무엇으로 정해질까요?

왜 이 방법을 쓰나

  1. 문제 상황: (1 − cos x)/x²의 x → 0 극한을 구하고 싶어요.
  2. 앞 방법의 한계: 한 번 미분하면 sin x/(2x) — 또 0/0이에요. 여기서 멈추면 답을 못 내요.
  3. 해법: 조건을 다시 확인하고 한 번 더 미분: cos x/2 → 1/2.
쉽게 말하면 — 출발 속도가 같으면, 가속도를 비교한다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

sin x/(2x)에서 분자가 sin 0 = 0이니까 답이 0 아니에요?

학교 수학으로 보면: 02장의 부정형 판정. 분자만 보지 말고 분모도 함께 봐요.

식 조각읽는 법뜻
(1 − cos x)/x²대입: (1 − 1)/0 = 0/0 → 미분
sin x/(2x)분자 (1 − cos x)′ = sin x, 분모 (x²)′ = 2x. 대입: 0/0 → 또 미분
cos x/2분자 (sin x)′ = cos x, 분모 (2x)′ = 2. 대입: 1/2 → 멈춤
숫자로 한 번 해 보기

x = 0.1: (1 − cos 0.1)/0.01 = 0.0049958 ÷ 0.01 = 0.49958

x = 0.01: 0.4999958

1/2 = 0.5로 모여요

참고: sin x/(2x)에 0.01을 넣으면 0.49999. 0이 아니라 1/2 근처예요

조수 하루 (수강생)

분자만 보고 0이라고 하면 안 되는구나. 분모도 0이니까 아직 경주 중이었어요!

일상으로 치면

정지 상태에서 출발한 두 선수는 처음 순간 속도가 둘 다 0이에요. 그래서 출발 직후의 거리 비는 「가속도의 비」로 정해져요.

수학에서는

(1 − cos x)과 x²는 x = 0에서 값도 0, 기울기도 0이에요(sin 0 = 0, 2·0 = 0). 그래서 기울기의 기울기(cos 0 = 1과 2)의 비 1/2이 극한이에요.

박사

버튼으로 풀어 보세요. 두 번째 식에서 ③을 누르면 어떻게 되나요?

주판봇

sin 0 = 0이니까 0! 한 번이면 충분해요.

초파리 연구원

분모 2x도 0이야. 0/0이면 아직 답을 쓸 수 없어.

로피탈 걸음 — 원자료 예제

풀이 — 한 걸음씩

  1. 첫 대입: (1 − cos 0)/0² = 0/0 → 미분.
  2. 한 번 미분: sin x/(2x). 다시 대입: 0/0 → 조건 확인(분모 2x의 기울기 2 ≠ 0) 후 한 번 더 미분.
  3. 두 번 미분: cos x/2. 대입: 1/2 → 보통 수! 멈추고 답 1/2.
  4. 표 확인: x = 0.1에서 0.49958, 0.01에서 0.4999958.
이 단계의 한계 — 두 번째 미분을 하기 전에도 점검표(특히 ③ 분모의 기울기 ≠ 0)를 다시 확인했어요. 반복할 때마다 점검표는 새로 시작해요.
박사의 해석 — (1 − cos x)는 0 근처에서 x²/2처럼 행동해요. 그래서 x²로 나누면 1/2. 「코사인은 0 근처에서 위로 열린 포물선처럼 생겼다」는 뜻이기도 해요.
원자료 인포그래픽 보기 (영어 그림)

원자료 matharium 「L'Hôpital's Rule」의 「Example」: (1 − cos x)/x² = sin x/(2x) = cos x/2 → 1/2.

2단계 · 매번 대입 — 멈출 곳을 아는 눈

방법: 미분 뒤 반드시 대입일상: 다 익었는지 젓가락으로 찔러 보기
박사

상황 질문 — 고구마를 찔 때 몇 분마다 젓가락으로 찔러 봐요. 다 익었는데 계속 찌면 물러지죠. 로피탈에서 「다 익었다」는 신호는 무엇일까요?

일상으로 치면

젓가락이 쑥 들어가면 다 익은 거예요. 거기서 불을 꺼요. 시간표대로 더 찌면 오히려 망쳐요.

수학에서는

미분할 때마다 대입해서 보통 수가 나오면 거기서 멈춰요. (eˣ − 1 − x)/x²는 두 번 미분해서 eˣ/2 → 1/2에서 멈추고, (eˣ − 1)/(x² + x)는 한 번 미분한 eˣ/(2x + 1)에서 이미 1이 나와서 멈춰요. 한 번 더 하면 오답(09장).

로피탈 걸음 — 두 번 할 때와 한 번에 멈출 때

풀이 — 한 걸음씩

  1. (eˣ − 1 − x)/x²: 0/0 → (eˣ − 1)/(2x): 0/0 → eˣ/2: 1/2. 멈춤.
  2. (eˣ − 1)/(x² + x): 0/0 → eˣ/(2x + 1): 대입 1/1 = 1. 바로 멈춤.
  3. 여기서 한 번 더 미분하면 eˣ/2 → 1/2. 그럴듯하지만 오답이에요(표로 0.995 → 1 확인).
  4. 규칙은 「몇 번」이 아니라 「부정형인 동안만」이에요.
이 단계의 한계 — 반복해도 끝나지 않는 경우(무한 루프)도 있어요. 07장 3단계에서 봐요.
박사의 해석 — 로피탈은 부정형을 풀어 주는 열쇠지, 계속 돌리는 손잡이가 아니에요. 문이 열리면(보통 수가 나오면) 열쇠를 내려놓아요.
「매번 대입」만 지켜도 09장 오답 노트의 절반은 피할 수 있어요. 여기서 잠깐 쉬어 가도 좋아요.

3단계 · 표로 답 확인하기 — 계산은 결정, 표는 검산

방법: 다가가기 표로 검산일상: 영수증 다시 보기
박사

상황 질문 — 계산대에서 계산이 끝나도 영수증을 한 번 훑어보죠. 로피탈로 구한 답도 「한 번 훑어보는」 방법이 있을까요?

일상으로 치면

영수증은 계산을 다시 하는 게 아니라 「이상한 숫자」를 찾는 용도예요. 3,000원짜리가 30,000원으로 찍혔으면 바로 보여요.

수학에서는

로피탈로 구한 답을 다가가기 표로 확인해요. x = 0.1, 0.01, 0.001을 넣은 값이 답 근처로 모이면 안심, 다른 곳으로 모이면 계산을 다시 봐요. 표는 증명은 아니지만, 큰 실수를 잡아 줘요.

검산 표 — 세 식 비교

풀이 — 한 걸음씩

  1. (1 − cos x)/x²: 0.49958, 0.4999958 … → 1/2 ✓
  2. (eˣ − 1 − x)/x²: 0.517, 0.5017, 0.50017 → 1/2 ✓
  3. (eˣ − 1)/(x² + x): 0.956, 0.995, 0.9995 → 1 ✓ (1/2이 아님!)
  4. 세 식 모두 계산과 표가 맞아요. 하나라도 어긋나면 계산을 다시 봐요.

박사의 해석 — 「계산으로 결정하고, 표로 확인한다」. AI가 낸 답을 믿기 전에도 똑같이 해요. 이 시리즈 전체의 습관이에요.
