확대하면 직선 — 접선과 두 함수의 비

핵심 질문 — 두 함수가 같은 점에서 동시에 0이 될 때, 그 근처에서 두 값의 비는 왜 「기울기의 비」와 같아질까?

03장에서 「매끄러운 곡선은 확대하면 직선」이라고 했어요. 이 생각을 0/0에 쓰면 로피탈의 정리가 거의 저절로 나와요. 분자와 분모가 a에서 둘 다 0이면, a 근처에서 둘 다 직선처럼 보이고, 직선 두 개의 비는 기울기의 비예요.

0.0001sin x를 직선 x로 바꿀 때 x = 0.1에서의 차이 (약)
1sin x/(eˣ − 1)의 기울기 비 cos 0/e⁰
4(x² − 4)/(x − 2)의 기울기 비 2·2/1
×100두 비가 거의 같아지는 확대 배율

  1. 무엇을: a 근처에서 곡선을 직선(접선)으로 바꿔 보는 접선 근사와, 두 함수가 a에서 동시에 0일 때 「값의 비 ≈ 기울기의 비」가 되는 이유를 봅니다.
  2. 왜 중요한가: 이것이 로피탈의 정리(05장)가 맞는 이유의 그림 설명이에요. 공식을 외우는 대신 그림으로 이해하면 조건을 잊지 않아요.
  3. 생활·현장에서는: 계산기 없던 시절의 근사 계산(sin 0.1 ≈ 0.1), 공학의 「작은 변화는 직선으로 본다」는 계산, 두 양의 변화율 비교에 그대로 쓰여요.

1

1단계 · 접선 근사 — 곡선을 잠깐 직선으로 바꿔 보기

방법: f(x) ≈ f(a) + f′(a)(x − a)일상: 지도 앱의 직선 거리
박사

상황 질문 — 계산기가 없을 때 sin 0.1을 어떻게 구할까요? 정확한 값은 몰라도 「거의 이 정도」라고 빨리 말할 방법이 있을까요?

왜 이 방법을 쓰나

  1. 문제 상황: 복잡한 함수값을 a 근처에서 빠르게 어림하고 싶어요.
  2. 앞 방법의 한계: 곡선 그대로는 계산이 어려워요(sin, eˣ 등).
  3. 해법: a 근처에서 곡선을 접선(직선)으로 바꿔요: 출발 높이 f(a)에서 기울기 f′(a)로 x − a만큼 간 높이.
쉽게 말하면 — 짧은 거리라면 곡선 길도 직선 길로 어림할 수 있다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

f(a) + f′(a)(x − a)… 기호가 세 개나 있어요.

학교 수학으로 보면: 중학교 일차함수: 점 (a, b)를 지나고 기울기가 m인 직선은 y = b + m(x − a).

식 조각읽는 법뜻
f(a)에프 a출발점 높이
f′(a)에프 프라임 a출발점에서의 기울기(03장)
(x − a)출발점에서 가로로 간 거리
≈거의 같다x가 a에 가까울수록 더 같아짐
숫자로 한 번 해 보기

sin x, a = 0: sin 0 = 0, 기울기 cos 0 = 1

그래서 sin x ≈ 0 + 1 × (x − 0) = x

x = 0.1: 진짜 sin 0.1 = 0.099833, 근사 0.1 → 차이 0.000167

x = 0.01: 진짜 0.0099998, 근사 0.01 → 차이 0.00000017

조수 하루 (수강생)

일차함수 공식에 기울기 자리만 미분을 넣은 거네요. 0 근처에서는 sin x를 그냥 x로 봐도 되는구나!

일상으로 치면

지도에서 가까운 두 곳은 굽은 길 대신 직선 거리로 어림해도 거의 맞아요. 멀리 갈수록 틀려지지만, 가까울수록 정확해요.

수학에서는

f(x) ≈ f(a) + f′(a)(x − a)는 a에서의 접선이에요. sin x ≈ x (0 근처), eˣ − 1 ≈ x (0 근처). 차이는 x가 줄어드는 것보다 훨씬 빨리 줄어요.

박사

x를 1.5에서 0.01까지 줄여 보세요. 빨간 차이 선이 어떻게 되나요?

주판봇

근사는 어디까지나 근사죠. 틀린 값이니 쓰면 안 돼요!

초파리 연구원

틀린 게 아니라 「x에 비해 차이가 0으로 가는」 값이야. 극한에서는 그게 중요해.

접선 근사 실험 — sin x와 직선 y = x

풀이 — 한 걸음씩

  1. a = 0에서 sin x의 접선은 y = x예요(출발 높이 0, 기울기 1).
  2. x = 1.5에서는 차이가 커요(0.5 정도).
  3. x = 0.1이면 차이 0.00017 — x의 0.17%밖에 안 돼요.
  4. x를 줄일수록 차이 ÷ x도 0으로 가요. 이것이 「확대하면 직선」의 숫자 버전이에요.
이 단계의 한계 — 접선 근사는 a 근처에서만 맞아요. 멀리 가면 크게 틀려요. 그리고 a에서 매끄럽지 않으면(뾰족점) 쓸 수 없어요.
박사의 해석 — 0/0 극한은 「a 근처」에서만 일어나는 일이라, 바로 이 근사가 정확해지는 자리에서 벌어져요. 그래서 로피탈이 통해요.
2

2단계 · 원자료의 확대경 그림 — 값의 비 ≈ 기울기의 비

방법: 두 곡선을 동시에 확대일상: 두 비탈길의 경사 비교
박사

상황 질문 — 두 비탈길이 같은 지점(높이 0)에서 시작해요. 시작점에서 한 걸음 걸었을 때, 두 길의 높이 비는 무엇으로 정해질까요?

왜 이 방법을 쓰나

  1. 문제 상황: f(a) = g(a) = 0일 때 lim f(x)/g(x)를 구하고 싶어요(0/0).
  2. 앞 방법의 한계: 대입하면 0/0, 약분은 sin·eˣ에서 안 돼요(02장).
  3. 해법: 1단계의 접선 근사를 분자·분모에 함께 써요: f(x) ≈ f′(a)(x − a), g(x) ≈ g′(a)(x − a). 나누면 (x − a)가 지워져서 f′(a)/g′(a).
쉽게 말하면 — 같은 곳에서 출발한 두 비탈길은, 한 걸음 뒤 높이 비가 경사의 비다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

(x − a)가 지워진다는 게 무슨 말이에요? 0인데 지워도 돼요?

학교 수학으로 보면: 중학교 약분: (3k)/(5k) = 3/5 (k ≠ 0). 극한에서는 x ≠ a인 곳만 보니 x − a ≠ 0.

식 조각읽는 법뜻
f(x) ≈ f′(a)(x − a)f(a) = 0이라 접선 근사에서 출발 높이가 사라짐
g(x) ≈ g′(a)(x − a)분모도 마찬가지
f(x)/g(x) ≈ f′(a)/g′(a)(x − a)를 약분. 단, g′(a) ≠ 0이어야 나눌 수 있음
숫자로 한 번 해 보기

f = sin x, g = eˣ − 1, a = 0: f(0) = 0, g(0) = 0 → 0/0

기울기: f′(0) = cos 0 = 1, g′(0) = e⁰ = 1 → 비 1

숫자로: x = 0.001에서 sin x/(eˣ − 1) = 0.000999999833 ÷ 0.0010005 ≈ 0.9995

x를 더 줄이면 1로 모여요

조수 하루 (수강생)

0/0이었던 게 「기울기 1 ÷ 기울기 1」로 바뀌었어요. 02장의 「빠르기」가 바로 기울기였네요!

일상으로 치면

두 비탈길이 같은 바닥에서 출발하면, 출발 직후 높이는 「경사 × 걸은 거리」예요. 걸은 거리는 같으니 높이 비 = 경사의 비.

수학에서는

f(a) = g(a) = 0이면 a 근처에서 f(x)/g(x) ≈ f′(a)/g′(a). 원자료 인포그래픽의 「Geometric meaning」 그림이 바로 이것이에요: 확대경 속 두 직선의 기울기 비.

박사

배율을 ×100 이상으로 올려 보세요. 「값의 비」와 「기울기의 비」가 어떻게 되나요?

주판봇

둘 다 0이니까 비도 0이죠!

초파리 연구원

0 ÷ 0은 0이 아니라고 02장에서 봤잖아. 확대해 보면 두 직선이 남아.

두 곡선 확대경 — 값의 비와 기울기의 비

풀이 — 한 걸음씩

  1. 초록 f = sin x와 빨강 g = eˣ − 1이 모두 x = 0에서 0을 지나요.
  2. 배율을 올리면 두 곡선이 모두 직선처럼 펴져요(03장).
  3. 오른쪽 점에서 f ÷ g를 계산하면 배율이 클수록 기울기 비 1에 가까워져요.
  4. (x² − 4)/(x − 2)로 바꾸면 기울기 비 = (2·2)/1 = 4 — 01장 표의 답과 같아요.
이 단계의 한계 — 이 그림은 f(a) = g(a) = 0 (0/0 꼴)이고 g′(a) ≠ 0일 때의 설명이에요. 두 함수가 함께 ∞로 가는 ∞/∞ 꼴은 「a에서의 접선」이 없어서 이 그림으로 설명되지 않아요(07장, 정확한 증명은 코시 평균값 정리).
박사의 해석 — 0/0의 「경주」(02장)를 확대경으로 보면 두 직선의 「경사 비교」가 돼요. 로피탈의 정리는 이 생각을 규칙 문장으로 정리한 것이에요.
원자료 인포그래픽 보기 (영어 그림)

원자료 matharium 「L'Hôpital's Rule」의 「Geometric meaning」: a 근처에서 f(x)/g(x)는 접선 기울기의 비 f′(a)/g′(a)에 가깝다.

원자료의 「Near a, the ratio f(x)/g(x) is close to the ratio of the slopes f′(a)/g′(a)」를 이 페이지에서는 「f(a) = g(a) = 0이고 g′(a) ≠ 0일 때」로 범위를 밝혀 적습니다. 원자료 위쪽의 「(or both limits are ±∞)」 경우에는 이 그림 설명이 그대로 맞지 않아요.

3단계 · 달리기로 다시 보기 — 남은 거리의 비 = 속도의 비

방법: 시간을 거꾸로 본 경주일상: 출발선에서 막 출발한 두 선수
박사

상황 질문 — 두 선수가 출발선(0)에서 동시에 출발했어요. 출발 0.01초 뒤, 두 선수가 간 거리의 비는 무엇으로 정해질까요? 출발 순간의 속도일까요, 나중의 속도일까요?

일상으로 치면

출발 직후에는 아직 속도가 거의 변하지 않았어요. 그래서 간 거리의 비는 「출발 순간 속도의 비」예요. 나중에 누가 더 빨라지든, 출발 직후의 비에는 영향이 거의 없어요.

수학에서는

위 선수 f(t) = 3t + t², 아래 선수 g(t) = 2t. t → 0일 때 f/g → 3/2 = f′(0)/g′(0). 위 선수가 나중에 가속(t²)해도 출발 직후의 비는 출발 속도(기울기)로 정해져요.

박사

이번엔 「달리기」 짝을 골라 확대해 보세요. 위 선수가 나중에 가속하는데도 비가 3/2로 가나요?

주판봇

위 선수가 가속하니까 결국 위 선수가 이기죠. 비는 ∞!

초파리 연구원

그건 t가 커질 때 얘기야. 우리는 출발 직후(t → 0)를 보고 있어.

출발선 확대경 — 두 선수가 간 거리의 비

풀이 — 한 걸음씩

  1. f(t) = 3t + t², g(t) = 2t. t = 0에서 둘 다 0.
  2. 출발 속도(기울기): f′(0) = 3, g′(0) = 2.
  3. 확대하면 t² 부분은 t보다 훨씬 빨리 작아져서 사라지고, 3t와 2t만 남아요 → 비 3/2.
  4. 극한이 묻는 것은 「그 자리 바로 옆」이에요. 멀리서 벌어지는 일(가속)은 상관없어요.
이 단계의 한계 — 「출발 속도의 비」로 답이 나오려면 아래 선수의 출발 속도 g′(0)가 0이 아니어야 해요. 둘 다 출발 속도가 0이면? → 06장 「한 번 더 미분」으로 가속도를 비교해요.
박사의 해석 — 극한은 「그 자리 바로 옆」만 본다. 이 원리 덕분에 복잡한 식도 그 자리의 기울기 두 개만으로 비가 정해져요.

AI 판단 코너 — AI가 낸 답, 그대로 믿어도 될까?

모아가 AI에게 「원자료 그림처럼, ∞/∞ 꼴도 두 접선 기울기의 비로 설명할 수 있어?」라고 물었어요.

AI 답변: 네. ∞/∞ 꼴도 a 근처에서 두 함수를 접선으로 바꾸면 f(x)/g(x) ≈ f′(a)/g′(a)가 됩니다. 그림 설명이 그대로 성립합니다.
박사

「규칙이 성립한다」와 「이 그림으로 설명된다」는 다른 말이에요. AI가 설명의 범위를 넓혀 말하면 그림의 전제(f(a) = 0)부터 확인하세요.
