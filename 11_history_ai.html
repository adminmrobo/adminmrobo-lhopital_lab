2단계 · 컴퓨터의 0/0 — 너무 가까이 가면 숫자가 망가진다

방법: 컴퓨터 계산과 극한 비교일상: 눈금이 1 mm인 자로 0.01 mm 재기
박사

상황 질문 — 눈금이 1 mm인 자로 0.01 mm 차이를 재면 어떻게 될까요? 두 길이가 똑같이 읽히지 않을까요? 컴퓨터에도 「눈금」이 있어요.

왜 이 방법을 쓰나

  1. 문제 상황: 컴퓨터로 (1 − cos x)/x²의 극한을 표로 확인하고 싶어요(06장).
  2. 앞 방법의 한계: x를 아주 작게 하면 cos x가 1과 구별되지 않아 1 − cos x = 0이 돼요. 컴퓨터는 0.5 대신 0을 내놓아요.
  3. 해법: 자릿수를 잃지 않게 식을 바꿔 써요: 1 − cos x = 2 sin²(x/2). 빼기가 사라져서 끝까지 정확해요. 그리고 x를 「적당히」 작게 써요.
쉽게 말하면 — 자의 눈금보다 작은 차이는 재지 말고, 재는 방법을 바꾼다.

3단계 · AI의 약속 0 · log 0 = 0 — 극한이 학습을 지킨다

방법: 극한값으로 약속하기일상: 시험에 안 나온 문제는 0점 처리
박사

상황 질문 — AI 모델이 「이 사진이 고양이일 확률 0」이라고 확신했어요. 엔트로피를 계산하려면 0 × log 0을 해야 하는데, log 0은 −∞예요. 컴퓨터는 어떻게 해야 할까요?

왜 이 방법을 쓰나

  1. 문제 상황: AI 모델의 확률 예측에서 엔트로피 −Σ p log p를 계산하고 싶어요.
  2. 앞 방법의 한계: p = 0이면 0 × log 0 = 0 × (−∞) — 부정형. 컴퓨터에 그대로 시키면 NaN이 나오고, NaN 하나가 평균 전체를 NaN으로 만들어 학습이 멈춰요.
  3. 해법: 08장 극한 lim (p→0⁺) p ln p = 0을 근거로 「0 · log 0 = 0」으로 약속해요. 많은 AI 도구가 이 약속을 써요.
쉽게 말하면 — 극한이 「이 자리는 0으로 채워도 된다」고 허락해 준다.

조수 하루 (수강생)

log 0은 −∞인데 0을 곱하면 0이라고 정해도 돼요? 그냥 편하려고 정한 거 아니에요?

학교 수학으로 보면: 08장 줄다리기: x · ln x → 0 (x → 0⁺). 고등학교 로그함수.

식 조각읽는 법뜻
−Σ p log p마이너스 시그마 피 로그 피확률들의 엔트로피(헷갈림 정도)
0 · log 0그대로는 0 × (−∞), 부정형 → 컴퓨터는 NaN

예측 (고양이 0.5, 강아지 0.5): 엔트로피 = −2 × 0.5 × ln 0.5 = 0.693

예측 (1, 0): 1 · ln 1 = 0, 0 · ln 0 = ? → 약속대로 0 → 엔트로피 0 (전혀 안 헷갈림)

p = 0.001이면 p ln p = −0.0069, p = 0.000001이면 −0.0000138 → 0으로 다가감

편하려고 정한 게 아니라, 다가가는 값이 0이라서 0으로 채운 거군요. 08장이 여기서 쓰이네!

일상으로 치면

시험에 나오지 않은 단원은 「0점 처리」해도 총점이 그대로예요. 빠진 자리가 아니라, 원래부터 기여가 없는 자리니까요.

수학에서는

확률 0인 항목은 엔트로피에 기여하지 않아야 자연스러워요. 실제로 p ln p는 p → 0일 때 0으로 다가가요(08장, 로피탈). 그래서 0 · log 0 = 0으로 약속해요. 약속 없이 그대로 계산하면 NaN이, 아주 작은 ε를 더하면 작은 오차가 생겨요.

초파리 연구원

「그대로 계산」을 골라 봐. 컴퓨터는 0 × (−∞)를 NaN이라고 해.

AI 채점표 — 0 · log 0 처리 방법 비교

풀이 — 한 걸음씩

  1. p = 0.5: 엔트로피 0.693. 처리 방법과 상관없이 같아요.
  2. p = 0(고양이 확률 0) + 「그대로 계산」: 0 × (−∞) = NaN. 학습 기록이 망가져요.
  3. 「극한값 0으로」: 엔트로피가 정확히 나와요. 근거는 lim p ln p = 0.
  4. 「ε 더하기」: NaN은 피하지만 아주 작은 오차가 섞여요. 실전 연습장 「AI 채점실」에서 ε 크기에 따른 오차를 볼 수 있어요.
이 단계의 한계 — 정답 쪽 확률이 0인 경우(−log 0 = ∞, 손실이 무한대)는 부정형이 아니라 진짜로 무한대예요. 그 경우는 약속으로 해결하지 않고, 모델이 확률 0을 내지 않게 막는 다른 방법을 써요.
박사의 해석 — AI 코드 속 작은 약속 하나에도 극한이 들어 있어요. 「왜 0으로 정했나?」라고 물을 수 있으면, AI가 내놓은 숫자의 근거를 따라갈 수 있어요.
