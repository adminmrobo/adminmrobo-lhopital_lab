# 로피탈 교실 — 0/0의 정체를 밝히는 수업

미분이 아직 헷갈리는 학생도 따라올 수 있게 만든 **로피탈의 정리** 연구실 해설 시리즈예요. matharium 「L'Hôpital's Rule」 인포그래픽과 로피탈 오용 사례 정리 글을 바탕으로, 극한 → 0/0 → 기울기·미분 → 접선 근사 → 로피탈의 정리 → 반복·∞/∞·변신 → 오답 노트 두 권 → 역사와 AI 순서로 12장에 나눴어요. 장마다 다른 수업 형식(1:1 토론, 조별 과제, 계산배틀, 발표수업, 역할극, 찬반 토론, 쪽지시험 등)으로 풀었어요.

- 선생님: 박사 · 조교: 초파리 연구원, 주판봇 · 수강생: 인턴 시아, 인턴 모아, 조수 하루, 미공개 X1·X2·X3
- 1조 「분자조」 시아·하루·X1 / 2조 「분모조」 모아·X2·X3 (로피탈은 분자와 분모를 따로 미분하니까요)
