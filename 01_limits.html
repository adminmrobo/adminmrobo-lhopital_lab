극한 — 가까워지기와 같아지기

핵심 질문 — x를 2에 「넣지 않고」 다가가기만 해도, 식의 값이 어디로 가는지 알 수 있을까?

로피탈의 정리는 극한을 구하는 도구예요. 그래서 먼저 극한이 무엇인지부터 잡아요. 극한은 「그 자리에 도착했을 때의 값」이 아니라 「그 자리로 다가갈 때 값이 향하는 곳」이에요. 도착하지 않아도 방향은 알 수 있어요.

01/n이 향하는 곳 (도착은 안 함)
4(x² − 4)/(x − 2)이 x → 2에서 향하는 곳
0/0x = 2를 바로 넣었을 때
없음|x|/x의 x → 0 극한 (두 길이 다름)

숫자 요약은 이 장의 예시 계산에서 나온 값입니다(실제 데이터가 아닌 설명용 값).

박사

처음 오신 분께 — 이 페이지를 3줄로

  1. 무엇을: x가 어떤 수에 한없이 다가갈 때 식의 값이 향해 가는 곳, 극한(lim)을 배웁니다.
  2. 왜 중요한가: 로피탈의 정리는 「대입하면 0/0이 되는 식」의 극한을 구하는 도구예요. 극한을 모르면 로피탈이 무엇을 계산하는지 알 수 없어요.
  3. 생활·현장에서는: 내비게이션의 「도착 예정 시각」처럼, 아직 도착하지 않았어도 지금 흐름으로 어디에 닿을지 말하는 일이 극한이에요.

미분을 아직 잘 몰라도 됩니다. 필요한 것은 장 안에서 처음부터 다시 설명해요. 그림을 움직여 보고, 밑줄 친 말을 누르면 뜻이 나옵니다.

영어 기호·약어 풀이 (펼치기)
  • lim — limit(극한)의 줄임말. lim 아래의 x → a는 「x가 a로 다가갈 때」라는 뜻
  • x → a — 엑스가 a로 간다. a에 한없이 가까워지되 a와 같아지지는 않음
  • x → 2⁻, x → 2⁺ — 2보다 작은 쪽(왼쪽)에서 / 큰 쪽(오른쪽)에서 다가감

극한은 「x = a를 넣은 값」이 아니에요. a 바로 그 자리가 비어 있어도(계산이 안 돼도) 극한은 있을 수 있어요. 이 한 문장이 로피탈 교실 전체의 출발점이에요.

1

1단계 · 가까워지기와 같아지기 — 1/n은 0이 될까

방법: 수열을 수직선에 찍기일상: 반씩 다가가는 개구리
박사

상황 질문 — 벽까지 1 m 떨어진 개구리가 매번 남은 거리의 일부만 뛰어요. 개구리는 언젠가 벽에 닿을까요? 그런데 「어디로 가고 있나」는 말할 수 있을까요?

일상으로 치면

개구리가 1, 1/2, 1/3, 1/4 … m 앞까지 다가가요. 벽에 「닿지」는 않지만, 개구리가 향하는 곳이 벽이라는 건 누구나 알 수 있어요.

수학에서는

n이 커지면 1/n은 0에 한없이 가까워지지만 0이 되지는 않아요. 이것을 lim (n→∞) 1/n = 0이라고 써요. 극한값 0은 「도착 예정지」이지 「도착한 값」이 아니에요.

박사

n을 1,000,000까지 올려 보세요. 빨간 점이 0에 닿나요?

주판봇

백만이면 0이나 마찬가지죠. 0이 됐다고 해요!

초파리 연구원

「마찬가지」는 수학 용어가 아니야. 0.000001과 0은 달라. 다만 「향하는 곳」은 0이지.

1/n 실험 — n을 키우면 점은 어디로 갈까

풀이 — 한 걸음씩

  1. n = 1, 2, 3 …일 때 1/n = 1, 0.5, 0.333 …으로 점점 작아져요.
  2. n = 1,000이면 0.001, n = 1,000,000이면 0.000001. 0과의 거리가 원하는 만큼 작아져요.
  3. 하지만 어떤 n에서도 1/n은 0보다 커요. 0에 「도착」하는 순간은 없어요.
  4. 그래서 극한값은 0이라고 말하되, 「1/n = 0인 n이 있다」고 말하지는 않아요.
이 단계의 한계 — 이 단계는 n이 자연수로 커지는 경우만 봤어요. 로피탈 교실에서는 대부분 x가 어떤 수 a로 다가가는 경우를 다뤄요. 다음 단계가 그것이에요.
박사의 해석 — 극한은 「아무리 작은 거리를 정해도, 그보다 더 가까워지는 순간이 온다」는 약속이에요. 계산기 화면의 0.000001은 그 약속의 한 장면일 뿐이에요.
여기서 한 번 멈춰도 괜찮아요. 「다가간다 ≠ 같아진다」 한 줄만 기억하면 다음 단계로 충분히 넘어갈 수 있어요.
2

2단계 · 다가가기 표 — 넣을 수 없으면 옆에 넣어 본다

방법: x = 1.9, 1.99, 1.999 … 넣기일상: 공사 중인 다리
박사

상황 질문 — 다리 한가운데 한 지점만 공사 중이라 막혀 있어요. 그 한 점의 높이를 재지 못해도, 양옆 다리 높이를 보면 그 점의 높이를 짐작할 수 있을까요?

왜 이 방법을 쓰나

  1. 문제 상황: (x² − 4)/(x − 2)에 x = 2를 넣으면 0/0이 돼서 값이 안 나와요.
  2. 앞 방법의 한계: 대입은 「그 자리에 도착해서 재는」 방법이라, 자리가 비어 있으면 쓸 수 없어요.
  3. 해법: 그 자리 대신 바로 옆(1.9, 1.99, 1.999 …와 2.1, 2.01 …)에 넣어 값이 모이는 곳을 봐요.
쉽게 말하면 — 막힌 한 점 대신 그 양옆을 재서, 그 점의 높이를 알아낸다.

수학 수식을 어려워하는 조수가 대신 물어봅니다

조수 하루 (수강생)

0/0이 나왔는데 왜 답이 4예요? 0 나누기 0은 계산이 안 되잖아요?

학교 수학으로 보면: 중학교 인수분해: x² − 4 = (x − 2)(x + 2). 그리고 함수의 그래프 읽기.

식 조각읽는 법뜻
lim (x→2)리밋, 엑스가 2로 갈 때x를 2에 다가가게 할 때 값이 향하는 곳을 묻는 표시
(x² − 4)/(x − 2)엑스 제곱 빼기 4, 나누기 엑스 빼기 2x = 2만 빼고 모든 곳에서 x + 2와 같은 값
= 4x = 2를 넣은 값이 아니라, 다가갈 때 향하는 값
숫자로 한 번 해 보기

x = 1.9: (3.61 − 4)/(−0.1) = (−0.39)/(−0.1) = 3.9

x = 1.99: (3.9601 − 4)/(−0.01) = 3.99

x = 2.01: (4.0401 − 4)/0.01 = 4.01

양쪽 모두 4로 모여요. 약분하면 x + 2라서 x → 2일 때 4.

조수 하루 (수강생)

x = 2에서는 계산이 안 돼도, 2 근처에서는 다 계산되네요. 그 값들이 4로 모이는구나!

일상으로 치면

다리의 공사 지점은 비어 있어도, 왼쪽 다리와 오른쪽 다리가 같은 높이로 이어져 있으면 그 점의 높이를 알 수 있어요.

수학에서는

(x² − 4)/(x − 2)의 그래프는 직선 y = x + 2에서 (2, 4) 한 점만 빠진 모양이에요. 그 빈 점의 높이 4가 극한값이에요. 표에서 x를 2에 가깝게 할수록 값이 4로 모여요.

박사

자릿수를 6까지 올려 보세요. 왼쪽 열과 오른쪽 열이 어디로 모이나요?

주판봇

2를 넣으면 0/0이니까 답은 「계산 불가」예요!

초파리 연구원

넣으면 안 되는 자리에 넣었잖아. 옆에 넣어 봐. 왼쪽도 오른쪽도 4로 가.

다가가기 표 — x를 2에 10배씩 가깝게

풀이 — 한 걸음씩

  1. x = 2를 그대로 넣으면 분자 0, 분모 0 → 0/0. 값이 정해지지 않아요.
  2. 2에서 0.1, 0.01, 0.001만큼 떨어진 곳에 넣으면 3.9, 3.99, 3.999와 4.1, 4.01, 4.001.
  3. 양쪽이 모두 4로 모이므로 lim (x→2) (x² − 4)/(x − 2) = 4.
  4. 그래프로 보면 직선 y = x + 2에 빈 동그라미 하나. 그 높이가 4예요.
이 단계의 한계 — 표는 몇 개의 x만 넣어 본 것이라 「증명」은 아니에요. 값이 모이는 듯 보이다가 아주 가까이에서 달라지는 식도 있어요(11장에서는 컴퓨터가 속는 경우도 봐요). 그래서 표는 「확인용」, 계산 방법(약분·로피탈)은 「결정용」으로 써요.
박사의 해석 — 0/0이 나왔다는 건 「답이 없다」가 아니라 「대입으로는 모른다」는 뜻이에요. 이 차이를 아는 것이 로피탈 교실의 첫 번째 열쇠예요.
3

3단계 · 왼쪽 길과 오른쪽 길 — 둘이 다르면 극한은 없다

방법: 좌극한·우극한 비교일상: 갈림길 끝의 두 마을
박사

상황 질문 — 같은 산꼭대기를 향해 왼쪽 등산로와 오른쪽 등산로가 있어요. 그런데 두 길이 다른 봉우리에 닿는다면, 「이 산의 꼭대기는 어디」라고 한 곳을 말할 수 있을까요?

일상으로 치면

왼쪽 길로 가면 A 마을, 오른쪽 길로 가면 B 마을에 닿아요. 「이 길들의 도착지」를 하나로 말할 수 없어요.

수학에서는

|x|/x는 x가 음수면 −1, 양수면 1이에요. 왼쪽에서 0으로 다가가면 −1, 오른쪽에서 다가가면 1. 두 값이 달라서 lim (x→0) |x|/x는 「없다」고 말해요. 극한이 있으려면 왼쪽 극한과 오른쪽 극한이 같아야 해요.

박사

식을 |x|/x로 바꿔 보세요. 표의 두 열이 같은 곳으로 가나요?

주판봇

−1과 1의 중간이니까 극한은 0이에요!

초파리 연구원

중간을 내는 건 반칙이야. 어느 쪽에서도 0 근처 값은 안 나와. 극한은 「없음」.

왼쪽·오른쪽 표 — 두 식 비교

풀이 — 한 걸음씩

  1. |x|는 x의 부호를 떼어 낸 크기예요. x = −0.1이면 |x| = 0.1이라 |x|/x = −1.
  2. x = 0.1이면 |x|/x = 1. 0에 아무리 가까이 가도 왼쪽은 −1, 오른쪽은 1 그대로예요.
  3. 왼쪽 극한 −1 ≠ 오른쪽 극한 1 → 극한 없음.
  4. 반면 (x² − 4)/(x − 2)는 양쪽 모두 4라서 극한이 있어요.
이 단계의 한계 — 이 시리즈에서 다루는 대부분의 식은 양쪽 극한이 같아요. 하지만 10장에서 「미분한 식의 극한이 없을 때」를 다룰 때 이 단계가 다시 필요해요.
박사의 해석 — 극한은 「어느 방향에서 다가가도 같은 곳」이어야 있다고 말해요. 한쪽만 보고 결론을 내리지 않는 습관이 나중에 오용을 막아 줘요.

AI 판단 코너 — AI가 낸 답, 그대로 믿어도 될까?

하루가 AI에게 「lim (x→2) (x² − 4)/(x − 2)를 구해 줘」라고 물었어요.

AI 답변: x = 2를 대입하면 (4 − 4)/(2 − 2) = 0/0입니다. 0을 0으로 나눌 수 없으므로 이 극한은 존재하지 않습니다.
박사

AI가 「대입했더니 계산 불가 → 극한 없음」이라고 하면 의심하세요. 극한은 그 자리 「옆」의 이야기예요. 표 한 줄만 만들어 보면 바로 확인돼요.
