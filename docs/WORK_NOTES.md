# 작업 메모 — 로피탈 교실 (lhopital_lab)

- 독자 진단: **혼합형, 수식 막힘 쪽이 강함**으로 가정. 미분 개념이 아직 확고하지 않은 학생(중학생~고등학생, 미분을 처음 배우는 대학 신입생 포함)을 주 독자로 둔다. 그래서 03장에서 기울기·미분을 처음부터 다시 세우고, 그 뒤에 로피탈을 꺼낸다.
- 주 독자 한 줄: 「미분을 배우긴 했는데 아직 감이 잘 안 오는 학생」.
- 원자료: ① matharium 「L'Hôpital's Rule」 인포그래픽 1장 (`img/source/src01.webp`), ② 구글 AI 모드 「로피탈 오용 사례」 개요 (사용자가 대화에 붙여 준 글, 수식은 복사 중 빠져 있어 예시를 복원).
- 원자료와 다른 값은 기본값대로 "원자료의 A를 이 페이지에서는 B로 바꿉니다"로 표기.
- 분야: 수학(미적분) 주 분야, 인공지능(수치 계산·손실 함수) 보조. 비유 앵커는 D(일상) — **달리기 경주**(0/0 = 동시 도착, 답 = 속도의 비)와 **확대경**(확대하면 곡선이 직선).

## 장 나누기 원칙 — "독자가 이해하기 쉬운" 크기
- 한 장 = 개념 2~3단계, 20~25분. 한 장에 새 기호는 최대 2개.
- 로피탈 규칙 자체(05장)보다 앞에 **극한(01) → 0/0(02) → 기울기·미분(03) → 접선 근사(04)**를 둔다. 미분이 약한 독자가 규칙을 "외우는" 대신 "왜 되는지" 알고 들어가게 하려는 것.
- 오용 사례는 한 장에 몰지 않고 **계산 실수형(09)**과 **조건 위반형(10)**으로 나눴다.
- 기본 과정: 01~07, 09, 11, 12 → 실전 연습장. 심화: 08(변신), 10(조건 위반) — 각 장 3단계는 접기.

## 검산한 숫자 (파이썬, 배정밀도)
- (x²−4)/(x−2): x=1.99 → 3.99, 2.01 → 4.01, 극한 4.
- (1−cos x)/x²: x=0.1 → 0.49958, 0.01 → 0.4999958, 극한 1/2. **컴퓨터 함정:** x=10⁻⁸에서 배정밀도 계산은 0.0 (1−cos x가 0으로 사라짐), x=10⁻⁶에서 0.500044.
- (eˣ−1−x)/x²: 0.1 → 0.5171, 0.01 → 0.5017, 극한 1/2.
- (eˣ−1)/(x²+x): 0.01 → 0.99507, 극한 1. 한 번 더 미분하는 실수를 하면 eˣ/2 → 1/2 (오답).
- x²/eˣ: x=10 → 0.00454, 20 → 8.2×10⁻⁷. ln x / x: 100 → 0.046, 1000 → 0.0069.
- x ln x: 0.01 → −0.046, 0.001 → −0.0069, 극한 0.
- (1+1/n)ⁿ: n=1 → 2, 12 → 2.6130, 365 → 2.7146, 8760 → 2.71813, e = 2.718281828.
- 1/x − 1/sin x: 0.01 → −0.00167, 극한 0.
- (x+sin x)/x: 1000 → 1.0008 (극한 1), 미분한 비 1+cos x는 0~2 사이에서 진동.
- 슈톨츠: f = x + sin x cos x, g = e^(sin x)·f. f/g = e^(−sin x)는 1/e ≈ 0.368과 e ≈ 2.718 사이를 오감. 미분한 비 = 2cos x / (e^(sin x)(f + 2cos x)) → 0.
- 속도계(실전 연습장): eˣ의 x=1 기울기를 (f(1+h)−f(1))/h로 잴 때 오차 — h=10⁻⁴: 1.36×10⁻⁴, h=10⁻⁸: 6.6×10⁻⁹(최소 근처), h=10⁻¹²: 4.3×10⁻⁴, h=10⁻¹⁵: 0.39.
