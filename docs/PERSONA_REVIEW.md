# 로피탈 교실 — 페르소나 검사 (2026-11-25)

주 관점: **수학이 너무 어렵고, 특히 미분 개념이 아직 확고하지 않은 공부하는 학생.** 평가는 빌드된 실제 페이지(12장 + 오리엔테이션 + 실전 연습장)를 열어 위젯을 조작한 결과로만 했어요. 자기 결과물이라 문제점 찾기에 무게를 뒀어요.

## 0. 대상 요약
- 극한(01) → 0/0(02) → 기울기·미분(03) → 접선 근사(04) → 로피탈 규칙(05) → 반복(06) → ∞/∞(07) → 변신(08, 심화) → 오답 노트 ①②(09, 10 심화) → 역사·컴퓨터·AI(11) → 종합(12) → 실전 연습장 3곳.
- 장마다 수업 형식이 다르고, 모든 단계에 상황 질문 · 왜/조수 수식 상자 · 그림 실험 · 풀이 · 한계 · 해석 · 퀴즈가 있어요.
- 핵심 메시지: 「0/0의 답은 빠르기(기울기)의 비」, 「규칙은 점검표 안에서만 안전」, 「AI·컴퓨터의 숫자도 확인한다」.

## 5. 정리
입문 쪽(A·B·F)은 비유와 버튼 실험을 높게 봤지만, 「미분을 그 자리에서 다시 보여 주지 않는다」, 「어디서부터 읽을지 모른다」는 두 가지에서 점수가 깎였어요. 전문가 쪽(D·E)은 반례와 컴퓨터 계산의 정확성을 높게 봤고, 수치 하나(04장 KPI)만 지적했어요. 교사(C)는 오답 정리를 수업 자료로 높게 봤지만, 몫의 미분 공식이 미배운 학생에게 혼란을 줄 수 있다고 했어요. 입문 독자 점수(3.5)가 전문가 점수(4.0~4.5)와 1점 가까이 벌어져 스킬 완료 기준(1점 이내)의 경계에 있었으므로, 입문 쪽 과제 1~3순위를 먼저 반영했어요. 1~6순위를 모두 반영한 뒤 다시 매긴 예상 점수는 A 4.0, B 4.0, F 4.0으로 전문가 점수와의 차이가 1점 안으로 들어와요. 남은 과제는 그림(7·8순위)으로, 지시문은 준비되어 있어요.
